## File Structure

Each game should have:
- `{game-name}.md` — Store listing text (title, descriptions, screenshots needed)
- `{game-name}-metadata.json` — Structured metadata for automation (optional)

## Store Listing Template

See individual game files for examples. All listings should include:

### Required Fields
- **App Name** (30 chars max)
- **Short Description** (80 chars max)
- **Full Description** (4000 chars max, formatted with emojis & bullets)
- **Category** (e.g., GAME_ADVENTURE, GAME_PUZZLE, GAME_CASUAL)
- **Content Rating** (EVERYONE for all JellyBolt games)
- **Tags** (comma-separated keywords)

### Asset Checklist
- [ ] 512×512 app icon (high-res PNG)
- [ ] 1024×500 feature graphic (JPG or PNG)
- [ ] 7× phone screenshots (1080×1920 or 1080×2400)
- [ ] Video (optional, YouTube URL)

## Content Rating (Standard for All Games)

All JellyBolt games target **EVERYONE (E)** rating:
