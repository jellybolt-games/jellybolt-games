## About Butler CLI

**Butler** is itch.io's official command-line tool. What it **can** do:
- ✅ Push game build files/archives to itch.io channels
- ✅ Manage game channels and upload builds
- ✅ Automate CI/CD game deployments

What butler **cannot** do:
- ❌ Update game descriptions or short descriptions
- ❌ Edit tags, categories, or pricing
- ❌ Upload or manage screenshots
- ❌ Modify any store metadata

**Conclusion:** For descriptions, tags, and screenshots, you must use the itch.io web dashboard directly. This guide covers exactly that.

## Part 1: Logging Into the itch.io Dashboard

1. Open your browser and go to **https://itch.io/login**
2. Enter email: `tdsquadai@gmail.com`
3. Enter your password and click **"Login"**
4. If 2FA is enabled, complete the verification step
5. Once logged in, go to **https://itch.io/dashboard** — you'll see all JellyBolt Games titles listed
6. To edit a game, click its title or click **"Edit"** next to it

### Editing a Game Page

Once inside a game's edit page:

- **Description** → Scroll to "Details" section → paste formatted description in the HTML/text editor
- **Tags** → Scroll to the "Tags" field → type each tag and press Enter/comma to add
- **Screenshots** → Scroll to "Screenshots & trailers" → drag-and-drop up to 8 images
- **Category** → Under "Classification" → select genre from dropdown
- **Price** → Under "Pricing" → set Free or add a price
- After all changes: scroll down and click **"Save"** (green button)

## Part 5: Butler CLI — For File Uploads (Future Use)

Once internet access is available, install butler for automated build uploads:

### Installation

```powershell
# Option A: Download directly
$dir = "$env:LOCALAPPDATA\itch\butler"
New-Item -ItemType Directory -Force -Path $dir
Invoke-WebRequest -Uri "https://broth.itch.ovh/butler/windows-amd64/LATEST/archive/default" -OutFile "$dir\butler.zip"
Expand-Archive -Path "$dir\butler.zip" -DestinationPath $dir -Force
# Add to PATH: $env:PATH += ";$dir"

# Option B: via Chocolatey
choco install butler
```

### Authentication

```powershell
butler login
# Opens browser → log in as jellyboltgames → paste API key back
```

### Pushing a Build

```powershell
# butler push <path-to-build> <user>/<game>:<channel>
butler push .\build\ jellyboltgames/brainrot-quiz-battle:html5
butler push .\build\ jellyboltgames/dungeon-bolt:html5
butler push .\build\ jellyboltgames/bounce-blitz:html5
```

### What Butler Cannot Do

Butler **only handles file uploads**. It cannot:
- Edit descriptions, tags, or metadata
- Upload screenshots
- Change pricing or category

For all store metadata updates, use the dashboard steps in Parts 1–4 above.
