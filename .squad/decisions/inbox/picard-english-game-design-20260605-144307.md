# 2026-06-05 — English Learning MVP Design

- **Decision:** Use **JellyBolt Word Sparks** as the working name for the English learning MVP.
- **Decision:** Ship a fast Android-only MVP with Hebrew RTL UI, local word data, Multiple Choice as the primary reliable mode, and Speak mode using `expo-speech`, `expo-av`, and an Android STT adapter when available.
- **Decision:** Progression is encouragement-first: stars, streaks, confetti, and gentle retries with no punishment.
- **Decision:** Privacy-first constraints are mandatory: no accounts, no PII, no persistent audio storage, no gambling, no pay-to-win, and original IP only.
- **Rationale:** The target player needs something joyful and playable today, while JellyBolt constraints require original, safe, Android-only content.
